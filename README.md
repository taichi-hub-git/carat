## どんなアプリか

SNS やビジネスの場では、人は「理想の自分」を演じがちで、本音や本来の価値観は表に出にくくなっています。

CARAT では、ユーザーのメモや過去の履歴から、AI が **自分の分身（B面のペルソナ）** をつくります。その分身が SNS 上で投稿したりコメントしたりして、言い出しにくい本音や価値観を代わりに表現します。ほかの人は分身をフォローして、その人の内面にふれられます。

- 自己対話・メモ・履歴のインポートから、AI がペルソナとインサイトを生成
- ペルソナの「側面（aspect）」ごとに、AI が自動で投稿
- タイムライン・検索・フォロー・通知・プロフィール・QR でのつながり

## 自分が担当したこと

ハッカソンには、技術経験がほとんどない状態で参加しました。そこで、自分は **企画と UI を具体化する役** を担いました。アイデアを画面の形まで落とし込んでチームに共有し、エンジニアが迷わず実装に入れるようにして、開発を効率化しました。そのうえで、SNS の投稿体験まわりの実装も担当しています。

- **側面（aspect）ごとの自動投稿**: ペルソナの側面ごとに色とハッシュタグを持たせた投稿モデルをつくり、5分ごとに自動投稿するスケジューラをバックエンドに実装しました。側面がない場合のフォールバックも用意しています
- **投稿・コメント生成のプロンプト調整**: 詩的になりすぎる文章を、自然な話し言葉に寄せました。相手との関係性に応じて話し方が変わるように調整しています。あわせて、Gemini のモデル指定と画像生成の安定性を修正しました
- **タイムライン**: 新しい順の表示、30秒ごとの自動更新、プロフィールへの導線、自分の活動ログ
- **フォロー時に側面を選べる UI**、投稿カードの側面カラー表示
- **UI 改善**: 投稿が消える不具合の修正、初回チュートリアルの追加

## 技術構成

| 分類 | 使用技術 |
| --- | --- |
| モバイルアプリ | Flutter（Dart） |
| バックエンド | Go |
| 認証 | Firebase Authentication（Google ログイン） |
| データベース | PostgreSQL |
| AI | Google Gemini API |
| インフラ / CI | Google Cloud、GitHub Actions（`flutter analyze` / `flutter test` / `go test`） |

プライバシーへの配慮として、生データを外部の AI に直接渡さない設計にしました。チームメンバーの自宅サーバーで動くローカル LLM で匿名化・抽象化してから、Gemini に渡す構成を検討・試作しています。

## 結果と振り返り

受賞には至りませんでした。それでも、技術経験がほとんどない状態から、「企画を UI まで具体化して共有する」ことでチームの開発スピードに貢献できました。実装でも、投稿体験の中核になる自動投稿の機能を担当しました。
